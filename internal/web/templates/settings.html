How costs are estimated

All models use the same illustrative workload: 46,000 input and 64,000 output tokens, including reasoning, per 1,000 transactions. This is rounded from our GLM eval; it is not a measured cost for every model. Estimates exclude retries, cache discounts, and credit purchase fees. Transactions handled by rules do not incur model charges.

Reference prices checked September 22, 2026, in USD per million input / output tokens: DeepSeek (Fireworks): $0.22 / $0.66; GLM (Fireworks): $0.15 / $0.50; Gemini (Google): $0.25 / $1.50. OpenRouter may route to a different eligible provider. These estimates are not a spending limit.
