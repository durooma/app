Good to know

A simpler way to get started

Select one or more UBS or Charles Schwab exports. The matching importer is detected automatically for each file.

Foreign-currency amounts are converted to {{.BaseCurrency}} using historical ECB rates. Duplicate rows (same date, description and amount) are skipped.

Leave the account name blank to keep separate Schwab exports (Individual, Joint Tenant, Equity Awards) distinct — each file is then named from its own header. A name entered above is applied to every file in the upload, which merges them into one account. Equity Awards grants are recorded at vest value; sales record only the resulting gain or loss.
